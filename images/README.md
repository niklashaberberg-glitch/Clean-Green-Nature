# Bildordner

`index.html` erwartet genau drei Dateien in diesem Ordner. Alles andere auf der
Seite – Icons, Materialkacheln, Wandtexturen, Illustrationen – ist als SVG direkt
in der HTML-Datei enthalten und braucht keine Bilddateien.

| Datei | Verwendung | Empfehlung |
|---|---|---|
| `cgc-logo-icon.png` | Logo in Kopfzeile und Fußzeile, Favicon | quadratisch, mind. 256 × 256 px, transparenter Hintergrund |
| `clean-green-cologne-logo.png` | Markenbild im Hero und Social-Media-Vorschau | quadratisch, mind. 1200 × 1200 px |
| `niklas-haberberg.jpg` | Porträt im Vision-Bereich und Vision-Fenster | quadratisch, mind. 400 × 400 px, Gesicht mittig |

Die Dateien einfach unter genau diesen Namen hier ablegen. Fehlen sie, bleibt der
Rest der Seite vollständig funktionsfähig – es erscheinen lediglich leere
Bildflächen.
