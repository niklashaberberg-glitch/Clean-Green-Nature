# Werkzeuge

Nur für den internen Gebrauch. **Diesen Ordner nicht auf den Webserver hochladen.**

* `lizenz-generator.html` – erzeugt das Schlüsselpaar für die Freischaltung von
  Pflichtbuch und stellt Kundenschlüssel aus. Lokal im Browser öffnen; die Datei
  arbeitet vollständig ohne Netz. Wer den privaten Schlüssel besitzt, kann
  beliebig viele Freischaltungen erzeugen – entsprechend verwahren.

Einzelheiten in `../app/README.md`, Abschnitt „Freischaltung einrichten".
